# Build log

Dated photos and short notes from each build or rebuild session.

Layout: `build-log/YYYY-MM-DD_<unit>_<topic>/` containing photos (JPEG/WebP, resized to
≤ 2000 px on the long side) and a `notes.md` with what was done, what was measured, and
anything that differs from the docs (also add that to `docs/as-built-status.md`).

Flight logs (`.ulg`) do not go here.
