# Build log

Dated photos and notes from each build or rebuild session.

Use `build-log/YYYY-MM-DD_<unit>_<topic>/` with photos (JPEG/WebP, up to 2000 px on the
long side) and a `notes.md` recording work, measurements and changes from the docs. Add
current configuration changes to [`docs/as-built-status.md`](../docs/as-built-status.md).

Flight logs (`.ulg`) do not go here.
